# 📸 We3 Surveillance Calculator

The **We3 Surveillance Calculator** is a tool designed for CCTV dealers to **calculate quotations, manage inventory, and track earnings** efficiently. 🛠️📄

## 🚀 **Features**

### 🏷️ **Quotation Management**
- **Instant Price Calculation**: Compute the total price of selected CCTV cameras, including **GST**.
- **Discount & Prepayment Support**: Dealers can **apply discounts** and **record prepayment amounts**.
- **Editable Quotations**: Modify active and fulfilled quotations anytime.
- **Generate PDF**: Easily save and access professional **PDF quotations**.

### 📦 **Camera Inventory Management**
- **Add/Edit/Delete Cameras**: Manage camera stock details.
- **Room Database for Offline Support**: Camera details are stored locally and **synced with Firebase when online**.

### 📊 **Earnings Tracking**
- **Real-time Updates**: Earnings dynamically update when quotations are completed.
- **Detailed Insights**: View customer details, prepayment amount, discounts, and quotation PDFs.

### 🔒 **Admin-Only Sections**
- **Authentication Required** for:
  - Editing & Managing Cameras
  - Accessing Active/Fulfilled Quotations
  - Viewing & Tracking Earnings
- **Open Access for Quotation Calculation** (Anyone can generate a quotation without login).

## 🛠 **Technologies Used**
- **Frontend**: Jetpack Compose (Android)
- **Backend**: Firebase (Cloud Storage & Authentication)
- **Local Database**: Room Database (Offline Support)

## 📖 **How to Use**
1. **Download the app**.
2. **Calculate a quotation** by selecting cameras (no login required).
3. **Login as Admin** to manage inventory, view/edit quotations, and track earnings.
4. **Generate & Save PDFs** for easy access.
5. **Sync data** when online for seamless updates.
