# 📸 We3 Surveillance Calculator

The **We3 Surveillance Calculator** is a powerful tool designed for CCTV dealers to efficiently calculate prices, generate professional quotations, and manage inventory with ease. 🛠️📄

## 📚 Features

### 📊 Price Calculator
- Calculate the total cost of selected CCTV cameras, including GST.
- Supports multiple cameras in a single quotation.

### 📝 Quotation Generator
- Generate professional PDF quotations for customers.
- **Active & Fulfilled Quotations**:
  - Keep track of ongoing (active) and completed (fulfilled) quotations.
  - Edit quotations before finalizing.
- **Earnings Section**:
  - Earnings dynamically update when an active quotation is marked as completed.

### 🛒 Inventory Management
- Maintain details of all available CCTV cameras.
- Admins can add, update, and remove product details.
- Firebase integration for cloud storage and authentication.

### 👤 Customer Management
- Add and manage customer details within the app.
- Track customer history for future reference.

### 📴 Offline Mode
- **Room Database** ensures functionality even without an internet connection.
- Work seamlessly in offline mode and sync data when back online.

## 🚀 How to Use

1. Download and install the app.
2. Log in as a dealer using authenticated credentials.
3. Select CCTV cameras, calculate prices, and generate quotations instantly.
4. Add customer details and track quotation status.
5. Manage product inventory and update details as needed.
6. Mark quotations as completed to track earnings.

## 🔧 Technologies Used

- **Frontend**: Jetpack Compose (Android)
- **Backend**: Firebase
- **Database**: Room Database (Offline Support)
